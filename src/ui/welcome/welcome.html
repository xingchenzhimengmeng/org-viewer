Welcome to Org Viewer

A modern, beautiful, and secure Org-mode previewer directly inside Google Chrome.

Step 1

Enable Local File Access

Chrome requires manual user consent before any extension can read local file:/// URLs. Without this permission, clicking local .org files cannot be rendered.

Checking permission status...
  1. Click the button above (or navigate to chrome://extensions).
  2. Find Org Viewer and click Details.
  3. Scroll down and toggle ON "Allow access to file URLs".
Step 2

Try It Out

Once enabled, you can open any .org file on your computer by dragging it into Chrome, or double-clicking it if Chrome is your default viewer.
