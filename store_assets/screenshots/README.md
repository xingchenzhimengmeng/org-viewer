# Chrome Web Store Screenshots Guide

The Chrome Web Store requires screenshots with dimensions **1280x800** or **640x400** pixels.

Recommended 4 Promotional Screenshots:

1. **screenshot-1-light-article.png**
   - **Scene**: In-place preview of a rich document (`sample_document.org`) in Chrome.
   - **Highlight**: Document header, GitHub-style typography, TODO / DONE badges, priorities, and code syntax block.
   - **Caption**: Instant in-browser preview for native .org files.

2. **screenshot-2-dark-mode.png**
   - **Scene**: Full dark mode view (`org-theme-dark`).
   - **Highlight**: High-contrast, easy-on-the-eyes dark theme, table formatting, and mathematical expressions.
   - **Caption**: Refined dark theme with full LaTeX math and table formatting.

3. **screenshot-3-outline-folding.png**
   - **Scene**: Table of Contents sidebar open, active heading highlighted, with one section folded.
   - **Highlight**: Smooth navigation outline and collapsible headings.
   - **Caption**: Interactive Table of Contents outline with section folding.

4. **screenshot-4-drag-drop-viewer.png**
   - **Scene**: Standalone popup/tab viewer showing the drag-and-drop zone and paste input.
   - **Highlight**: Easy offline access without opening Emacs.
   - **Caption**: Drop files or paste text for instant offline rendering.
